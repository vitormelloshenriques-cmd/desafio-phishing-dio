# Desafio de Projeto: Criação de um Phishing com o Kali Linux

Este repositório contém a documentação e o desenvolvimento do desafio prático do Santander Bootcamp Cibersegurança na [DIO](https://dio.me), focado na simulação de testes de intrusão[cite: 3].

## 🛠️ Ferramentas Utilizadas
* **Kali Linux / Máquina Virtual**
* **Social-Engineer Toolkit (setoolkit)**

## 📋 Descrição do Projeto
O objetivo deste laboratório é demonstrar de forma prática o funcionamento de páginas de phishing para fins educacionais e de conscientização sobre segurança da informação, utilizando o vetor de ataques de engenharia social[cite: 3].

### Passos Realizados:
1. Configuração do ambiente e inicialização da ferramenta `setoolkit`.
2. Seleção do módulo de ataques de engenharia social (*Social-Engineering Attacks*).
3. Configuração do vetor para clonagem de páginas de login em ambiente controlado.
4. Documentação do fluxo de testes e análise dos riscos associados.
